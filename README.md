## 1. Мета роботи
Ознайомитися з середовищем розробки Visual Studio Code, навчитися створювати класи та працювати з базовими елементами ООП у C#. Налаштувати середовище розробки та системи контролю версій Git/GitHub.

---

## 2. Індивідуальне завдання (Варіант 1)
Реалізувати клас `Book`:
* **Поля:** `title`, `author`.
* **Властивість:** `Year`.
* **Метод:** `GetInfo()` — повертає рядок із даними книги.

---

## 3. Структура проєкту
* `lab1v1/Book.cs` — клас, що описує об'єкт книги.
* `lab1v1/Program.cs` — головний файл із точкою входу `Main`, де створюються та тестуються об'єкти.
* `.gitignore` — конфігураційний файл для виключення системних та тимчасових файлів .NET.
